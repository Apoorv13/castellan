## What the data is

Every secret, key, token, password, email address, phone number, card number, ID and name in these files is **synthetic**. Each was generated by the frozen generators in `eval_data/` and has valid-looking structure. None is a real credential or a real person's data. The few documented example values (such as the AWS documentation example keys and the RFC 7519 example JWT) are public test values, used as published.

Secret scanners, including GitHub push protection and Gitleaks, will flag these files. That is expected, and `.gitleaks.toml` allowlists them. Please do not report them as leaks.
